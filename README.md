# Paradise Nursery

Paradise Nursery is an online plant shop application built with React and Redux.

## Features
- Browse houseplants by category
- Add plants to a shopping cart
- Increase, decrease, and remove cart items
- Dynamic cart item count
- Dynamic item and cart totals
- Responsive navigation between Home, Plants, and Cart pages

## Project
This project demonstrates React components, React Router, Redux Toolkit, and dynamic e-commerce interactions.
